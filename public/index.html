What this is. Common Ground is an agentic planner: it grounds free-text likes to real entities with Qloo Entity Search, pulls cross-domain taste affinities from the Qloo Insights API (music ↔ film ↔ dining), scores candidates by maximin (it maximizes the least-excited member's affinity estimate), and replans when someone pushes back.

What the numbers mean. Qloo affinities describe aggregate cultural patterns across large groups - they are evidence of association, never a prediction about any individual. No names, emails, or other personal data are ever sent to Qloo; only taste signals (entity IDs) leave this app. The Qloo API key stays server-side.

Multi-device by design: the whole session travels in a share link - everyone answers from their own phone, no accounts, nothing stored on a server. Built for the Qloo Agentic Hackathon. Open source (MIT).
