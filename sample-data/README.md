# Sample data notice

Files under `api/lib/sample-data.js` power SAMPLE MODE: they exist only so the
product flow can be demonstrated before a live Qloo hackathon API key is
configured. Every entity, affinity score, and rationale in that file is
invented for demonstration and is badged as SAMPLE in the UI and in every
API response (`"mode": "sample"` plus an explicit note). No sample value is
presented as real Qloo output.
